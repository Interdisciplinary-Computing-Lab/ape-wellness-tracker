APE WELLNESS TRACKER
===================

A desktop application for tracking ape nutrition and wellness data.

QUICK START:
1. Double-click ApeWellnessTracker.exe
2. Register a new account or login
3. Start tracking your apes' nutrition!

FEATURES:
- Add and manage ape profiles with photos
- Log feeding sessions and nutrition data
- Track calories and meal history
- Generate detailed reports
- Export data to CSV/JSON
- User authentication and security

SYSTEM REQUIREMENTS:
- Windows 10 or later (or macOS/Linux)
- 100MB free disk space
- No additional software required

FIRST TIME SETUP:
1. Run the application
2. Click "Register" to create an account
3. Login with your credentials
4. Start adding apes and logging meals

TROUBLESHOOTING:
- If the app won't start: Make sure you have Windows 10 or later
- If you get an error: Try running as administrator
- For login issues: Make sure you're using the correct email/password
- If data seems missing: Check that you're logged in with the right account
