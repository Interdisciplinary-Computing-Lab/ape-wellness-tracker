APE WELLNESS TRACKER - DESKTOP APPLICATION
==========================================

Thank you for using the Ape Wellness Tracker desktop application!

QUICK START:
------------
1. Double-click "ApeWellnessTracker.exe" to launch the application
2. The first time you run it, click "Register" to create your account
3. Login with your credentials
4. Start tracking your apes' nutrition and wellness data!

WHAT'S INCLUDED:
----------------
- ApeWellnessTracker.exe - The main application (just double-click to run)
- RESEARCHER_INSTRUCTIONS.txt - Detailed instructions and troubleshooting
- This README.txt file

SYSTEM REQUIREMENTS:
--------------------
- Windows 10 or later (64-bit)
- 200MB free disk space
- No internet connection required
- No Python or other software installation needed

IMPORTANT NOTES:
----------------
✓ The application runs completely offline
✓ All your data is stored locally on your computer
✓ No data is sent to external servers
✓ Your data is secure and private
✓ You can export your data at any time

FIRST LAUNCH:
-------------
The first time you run the application, it may take 5-10 seconds to start.
This is normal - the application is setting up its internal files.
Subsequent launches will be faster.

TROUBLESHOOTING:
----------------
If you encounter any issues:

1. Windows Security Warning:
   - If Windows Defender or your antivirus shows a warning, click "More info" then "Run anyway"
   - This is normal for applications that aren't digitally signed
   - The application is safe to use

2. Application won't start:
   - Try right-clicking the .exe and selecting "Run as administrator"
   - Make sure no other instance of the app is running
   - Check that you have enough disk space

3. Window is too small:
   - You can resize the window by dragging the corners
   - The minimum size is 1024x768 pixels

4. Forgot your password:
   - Contact the administrator for password reset
   - Email: dylandaner@me.com or zmielko@highlands.edu
